# Meals 🍲

تطبيق وصفات عربي متجاوب مع الهاتف، يعمل بالكامل في المتصفح دون حساب أو خادم.

## التشغيل المحلي

يتطلب Node.js 22.12 أو أحدث.

```sh
npm ci
npm run dev
```

## نسخة النشر على Netlify

```sh
npm run build
```

ارفعي **مجلد dist** في Netlify Drop، أو اربطي المستودع مع Netlify؛ الملف `netlify.toml` يحدد أمر البناء ومجلد النشر تلقائيًا. لتجربة نسخة الإنتاج محليًا: `npm run preview`.

## الاختبارات

```sh
npm test
```

تتحقق من اكتمال كل وصفة والمكونات والسعرات والحصص والتصنيف الصحي.

## المميزات

- 90 وصفة: 42 طبقًا، و24 حلوى، و24 مشروبًا من مطابخ عربية وغربية وصينية وعالمية.
- أقسام مستقلة للأطباق والحلويات والمشروبات، مع أنواع فرعية ومطابخ وفلاتر للصحي وغير الصحي والسعرات والبحث بالمكونات.
- مكونات وخطوات تحضير، وتعديل الحصص والكميات والسعرات الإجمالية.
- قائمة مكونات قابلة للتأشير ومفضلة محفوظة محليًا في المتصفح.
- أيقونة SVG وخط عربي مستضاف محليًا؛ لا توجد خدمات أو مفاتيح خارجية مطلوبة.

الوصفات الأساسية في `src/recipes.js`، والوصفات الموسعة في `src/expanded-recipes.js`. لكل وصفة قسم `kind` ونوع فرعي `subcategory` وتصنيف `health` وسبب التصنيف `healthReason`. أضيفي وصفات إلى القائمة بنفس البنية. كمية كل مكوّن وسعراته تخص كامل الوصفة الأساسية، ويحسب التطبيق السعرات لكل حصة تلقائيًا. السعرات تقديرية، وليست بديلًا عن تقييم غذائي متخصص. التصنيف الصحي إرشادي بحسب السكر المضاف والدهون والمكونات، وليس تقييمًا طبيًا أو مبنيًا على السعرات وحدها. الوصفات لا تمثل جميع وصفات العالم، ويمكن توسيع المجموعة دون حد ثابت في الكود.

المفضلة خاصة بالمتصفح والجهاز الحالي ولا تتزامن بين الأجهزة. العمل المحلي متاح عبر خادم التطوير؛ لا تفتحي index.html مباشرة. يمكن نشر مجلد dist على أي استضافة ملفات ثابتة.
